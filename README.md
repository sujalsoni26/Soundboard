# Meme Soundboard

A modern, production-ready meme soundboard built with Next.js. Play sounds instantly, favorite memes, search by tags, assign keyboard shortcuts, upload custom clips, and install as a PWA for offline use.

## Live Demo

The site is deployed at **[https://soundboard-sand-eta.vercel.app/](https://soundboard-sand-eta.vercel.app/)**.

## Tech Stack

- **Next.js 16** (App Router)
- **TypeScript**
- **Tailwind CSS v4**
- **Howler.js** for low-latency audio
- **Framer Motion** for animations
- **@ducanh2912/next-pwa** (maintained fork of next-pwa)
- **Supabase** (optional) — auth, cloud sync, custom uploads, admin settings
- **LocalStorage** for guest mode persistence

## Supabase Setup (optional)

The app works fully offline/guest without Supabase. To enable sign-in and cloud sync:

1. Create a project at [supabase.com](https://supabase.com)
2. Copy `.env.local.example` to `.env.local` and fill in:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY` (server-only)
3. Run migrations in **SQL Editor** (in order):
   - `supabase/migrations/001_initial_schema.sql`
   - `supabase/migrations/002_password_recovery.sql`
   - `supabase/migrations/003_catalog_and_submissions.sql`
   - `supabase/migrations/004_fix_rls_recursion.sql`
4. Upload built-in catalog to Supabase Storage (one-time):
   ```bash
   npm run upload:catalog
   ```
   After this, the app serves sounds from Supabase instead of `public/sounds/`.
5. In **Authentication → URL Configuration**, add:
   - Site URL: `http://localhost:3000` (and your Vercel URL in production)
   - Redirect URLs: `http://localhost:3000/auth/callback`, `https://your-domain.vercel.app/auth/callback`
6. In **Authentication → Providers**, enable **Email** and turn **off** “Confirm email” (password sign-in works immediately)
7. Restart dev server: `npm run dev`

### Promote an admin

After signing up once, run in the SQL Editor:

```sql
update public.profiles set role = 'admin' where email = 'you@example.com';
```

Then visit `/admin` to edit site settings and **review pending sound uploads**.

### Upload workflow

- **Guests** cannot upload sounds (upload button hidden).
- **Signed-in users** submit uploads (max **3MB**) for admin review.
- **Pending** uploads are private to the uploader (synced via their account).
- **Approved** → copied to public `catalog-sounds` bucket for everyone.
- **Rejected** → stays private to that user only.

### What syncs when signed in

Favorites, hidden sounds, custom names, playlists, recent history, play counts, settings, keyboard shortcuts, and custom uploads (stored in Supabase Storage when logged in).

Guest mode continues to use LocalStorage only — no account required.

## Audio Architecture

The centralized `audioManager` singleton (`src/lib/audio-manager.ts`) wraps Howler.js:

| Method | Purpose |
|--------|---------|
| `preloadSound()` | Loads audio into memory ahead of time |
| `playSound()` | Instant playback with overlap/queue/single modes |
| `stopSound()` | Stops a specific sound |
| `stopAllSounds()` | Global mute via `Howler.stop()` |
| `setVolume()` | Global volume control |

**Preloading strategy:** First 8 sounds preload immediately; remaining sounds preload during browser idle time via `requestIdleCallback`. Each sound gets a pool of 3 Howl instances for overlapping playback without re-decoding.

**Overlap modes** (Settings):
- **Overlap** — multiple sounds play simultaneously (default)
- **Single** — stops all before playing
- **Queue** — plays one after another

## Adding New Sounds

1. Drop your audio file into `public/sounds/` (MP3, WAV, OGG, WebM)
2. Add an entry to `src/data/sounds.ts`:

```typescript
{
  id: "my-meme",
  slug: "my-meme",
  title: "My Meme",
  file: "/sounds/my-meme.mp3",
  category: "Classic",
  tags: ["funny", "reaction"],
  emoji: "😂",
  duration: 1.2,
}
```

3. Run `npm run dev` — the sound appears in the grid and is preloaded automatically.

Replace placeholder `.wav` files generated by `npm run generate:sounds` with your real meme audio.

## Converting to Android/iOS with Capacitor

This app is frontend-only and PWA-ready, making it a strong Capacitor candidate:

```bash
npm install @capacitor/core @capacitor/cli
npx cap init "Meme Soundboard" com.yourname.soundboard
npm run build
npx cap add android
npx cap add ios
npx cap sync
```

**Key steps:**
1. Set `webDir` in `capacitor.config.ts` to `out` if using static export, or point to your deployed URL
2. For native builds with bundled assets, add `output: 'export'` to `next.config.ts` (note: disables some Next.js server features)
3. Use `@capacitor/haptics` for native vibration instead of the Web Vibration API
4. Use `@capacitor/share` for native share sheets
5. Open in Android Studio / Xcode: `npx cap open android` / `npx cap open ios`

## Features

- Responsive sound grid with play animations
- Real-time search (title, tags, category)
- Category & view filters (All, Favorites, Recent, Trending)
- Favorites & recently played (LocalStorage)
- Keyboard shortcuts with help modal
- Random meme & random-in-category buttons
- Stop all & global volume control
- Custom sound uploads (signed-in only, admin approval, 3MB cap)
- Sign in with **email + password** — sync favorites & playlists across devices
- **Security question** recovery for forgotten passwords (set at signup)
- Welcome prompt on first visit with **Continue as guest** option
- Admin panel at `/admin` for site settings (admin role required)
- Shareable URLs: `/sound/vine-boom`
- Local play counts & trending section
- Dark mode (default) + light mode
- PWA installable with offline audio caching
- Mobile-optimized tap targets & haptic-ready architecture
